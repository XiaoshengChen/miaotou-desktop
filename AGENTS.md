# Miaotou Desktop

- Keep one active thing. Replacement archives the unfinished thing; completion is idempotent and stores a finished record.
- Preserve the two-zone aqua/mint card, dark green companion, readable task and one auxiliary sentence. Fireworks happen only after completion.
- Mac targets macOS 14+. Foundation Models must be availability/language gated with an offline fallback. Windows is native WPF and has a tray entry.
- Data is local. Do not imply cross-device automatic sync exists.
- Never commit personal app records, local paths, credentials, signing material, developer account identifiers, build logs or private screenshots. Run scripts/check-public.py before publishing.
- Build outputs belong in ignored dist/. Keep generated docs clearly labeled as concepts vs native renders.
- Public release builds are unsigned/local-signed previews unless an explicit signing process has been configured. Do not publish certificates or API credentials.
